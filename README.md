# citas-diaria de Sadhguru 

Script de python que hace 'cita-diaria'. Y te da la cita del día, o la fecha que le indiques, por ejemplo, con: fecha='january-01-2022'. En el tamaño para posts.

O también se puede indicar:

cita-diaria imagen='' cita=''

y aleatoria con el script:

'cita-random', que tienes desde 2021 en español.

Se le puede indicar el idioma, con inglés: idioma='en'
Y solo la imagen:

cita-diaria imagen

cita-diaria imagen idioma='en'
